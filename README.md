Car Showroom Management Database
Project Overview

This project is a simple Car Showroom Management Database developed using MySQL as part of the Route Upskill Academy SQL Part Project.

The database manages car brands, car models, customers, and their purchases.

Database Tables

The project consists of four tables:

Brands – Stores car brand information.
Models – Stores car model names, prices, and their associated brands.
Customers – Stores customer names and contact details.
Purchases – Records customer purchases and purchase dates.
